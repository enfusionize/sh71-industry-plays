# Repository Guide

Based on the actual files present in the repository, the layout is as follows:

- `README.md`: Contains the scope of the project, details about the generated files, and a link to download the repository as a ZIP file.
- `index.html`: A self-contained HTML report of the verified industry plays. Contains 10 industry sections, with a total of 12 structured `<article>` elements. Thin evidence is labeled in the sections with empty results.
- `captures/`: Directory containing SVG frames that act as composed layouts for the index.
  - `captures/report-1440.svg`: Desktop-width layout frame (1440px wide).
  - `captures/report-390.svg`: Mobile-width layout frame (390px wide).
